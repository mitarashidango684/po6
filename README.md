制作実績・対応サービス・制作の進め方を紹介し、制作依頼や採用の問い合わせにつなげる静的サイトです。

**公開先**：https://mitarashidango684.github.io/po6/

- HTML5 / CSS3 / JavaScript（フレームワーク・ビルド不要）
- CSS Grid / Flexbox / メディアクエリ / CSS変数
- Google Fonts：Noto Sans JP、DM Sans（未接続時はシステムフォント）
- GitHub Pages

## 情報設計

1. ファーストビュー：提供価値と作品・相談への導線
2. 制作実績：3件の詳細事例と6件の教材・Figma作品を、実際のHTMLを使ったプレビューとともに紹介
3. 制作の考え方：情報整理・行動導線・認識合わせ・AI活用
4. サービス：Webサイト・LP・修正更新の料金目安
5. 制作の進め方・プロフィール・FAQ
6. 問い合わせ：メール／ランサーズ

## 実装上の工夫

- 単一HTMLにCSS・JavaScript・作品プレビューを収め、更新と持ち運びを簡単にしています。
- プレビューは2026年10月12日時点の公開リポジトリのHTMLを利用。スクリプト・リンク操作を無効化し、sandbox付きiframe内で表示しています。画面比率に応じてResizeObserverで縮小します。
- 実績プレビューは静止画ではありません。元サイトを変更しても自動更新されません。
- メール相談は選択内容に応じた件名と本文を用意するmailtoリンクです。バックエンド送信・入力データの保存は行いません。
- モバイルメニューは開閉状態をaria-expandedで伝え、Escapeキーで閉じられます。
- FAQはdetails/summaryを使用。JavaScriptが無効でも本文・FAQ・メールリンクを使えます。
- キーボードフォーカス、スキップリンク、動きを減らす設定に対応しています。
- スマートフォンの固定CTAは問い合わせセクションが見えると非表示になります。

## 起動・編集

`index.html`をブラウザで開くだけで確認できます。インストールやビルドは不要です。

必要な場合はこのディレクトリで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` を開いてください。

| 内容 | 対象 |
| --- | --- |
| 配色・書体 | 冒頭の`:root` |
| メインコピー | `#hero-title` |
| 実績紹介・リンク | `#works` |
| 料金 | `#services` |
| プロフィール | `#about` |
| 連絡先・メール本文 | `#contact`と末尾のJavaScript |

プレビューを差し替える場合は、対応iframeの`srcdoc`を更新してください。元サイトのスクリプトやフォームは埋め込まず、サンドボックスを維持します。プレビュー内のロゴは元作品の画像をWebP化して内包しています。
